GeoAlertNER — Project Story

AI-Driven Disaster Early Warning & Evacuation System for NER, India

🎯 Problem This Solves

India's North Eastern Region (Assam, Meghalaya, Sikkim & 5 other states) faces some of the world's highest landslide & flash flood risk. Existing warning systems are fragmented, English-only, and require constant internet connectivity — leaving remote hill communities with zero advance warning. GeoAlertNER addresses this with AI hazard prediction, offline-first PWA citizen reporting, and multilingual voice alerts.

🧠 ML / AI Layer
Custom Random Forest & Gradient Boosting ensemble trained on 9 geological, hydrological & meteorological features: slope angle, 24h rainfall, soil moisture, elevation, NDVI, lithology code, drainage distance, tilt rate & rain rate. Model returns probabilistic hazard scores with evacuation advisories.
scikit-learn NumPy Pandas Random Forest
🗺️ GIS & Spatial Layer
Interactive Leaflet.js map with GeoJSON hazard zone polygons, live IoT sensor markers, safe shelter icons, and dynamically drawn evacuation corridors. Supports real-time heatmap overlay from backend risk scores.
Leaflet.js GeoJSON Shapely PostGIS-ready
⚡ Backend API
FastAPI serving 14+ REST endpoints across Auth, Risk, Sensors, Evacuation, Shelters, Weather, Telemetry & Helplines. JWT Role-Based Access Control with 3 roles: Citizen, Field Officer, Admin. Pydantic v2 schema validation, SQLAlchemy ORM, async-ready.
FastAPI SQLAlchemy JWT / RBAC SQLite
📱 Frontend & PWA
Zero-framework Vanilla JS ES6 with offline Service Worker, IndexedDB queue for citizen reports, Chart.js forecast visualization, multilingual i18n (Assamese, Bengali, Hindi, English), and Web Speech API TTS voice alerts.
Vanilla JS ES6 PWA / SW Chart.js Web Speech API
